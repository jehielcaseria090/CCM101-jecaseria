# Mission Reflection – Laboratory 2

## 1. Which cloud infrastructure component do you think is the most important? Why?
For me networking is the important part. Compute and storage are useless if no one can reach them. In my KillerCoda server I used the hostname -I command to find the IP address. Without that IP address the server would just sit there doing nothing. The KillerCoda server needs the IP address to work. So I think networking is what makes everything else actually work. Networking is really important.

## 2. How does Linux support cloud computing?
Linux supports cloud computing because most cloud servers run on Linux. Linux is free, light and easy to control using commands. In this lab I used commands like uname -r and df -h to check the system. These commands let me see everything about the Linux server without needing a mouse or graphic interface. Linux is fast and simple to manage servers at once. This is why cloud engineers use Linux a lot.

## 3. Why is technical documentation important before deploying infrastructure?
Documentation is important because it helps other people understand what was built and why. If a company deploys servers without writing anything down it will be hard to fix problems or explain decisions to new engineers. Documentation helps me remember what I did. Why since I might forget later. Writing things down is really helpful.
