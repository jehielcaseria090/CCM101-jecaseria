# Cloud Platform Comparison

## Comparison Table

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 (App Engine) / 2011 (full GCP) |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity Service | AWS IAM | Azure Active Directory (Entra ID) | Cloud IAM |
| Primary Strength | Broadest service catalog | Microsoft ecosystem integration | AI/ML and Kubernetes |
| Ideal Organizations | Startups to enterprises | Microsoft-based enterprises | Data/AI-driven companies |

## Questions

**1. Which cloud provider offers the broadest range of services?**
AWS has the services compared to the other two. AWS started back in 2006 so AWS had a lot time to build up all these new tools.

**2. Which provider best integrates with Microsoft technologies?**
Azure works well if you already use Microsoft tools. Since Microsoft made Azure Azure connects easily with Windows and Office 365.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
GCP is the choice if you care about AI and Kubernetes. Google is the one that made Kubernetes and Google also built TensorFlow for AI.

**4. Which cloud platform would you personally choose and why?**
I would personally choose AWS because AWS has the services and so many companies use AWS. AWS also has a ton of guides which makes AWS easier to learn.
