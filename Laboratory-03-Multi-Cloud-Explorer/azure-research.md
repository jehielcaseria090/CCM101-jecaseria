\# Microsoft Azure Research



\## Brief Overview

Azure is Microsoft's cloud platform, launched in 2010. Best known for integration with Windows Server, Active Directory, and Microsoft 365.



\## Global Infrastructure

Regions grouped into Geographies, with Availability Zones for fault isolation, plus Azure Edge Zones.



\## Cloud Management Console

Azure Portal (web), Azure CLI, Azure PowerShell, Azure Cloud Shell.



\## Four (4) Core Services

1\. Azure Virtual Machines

2\. Azure Blob Storage

3\. Azure Active Directory (Microsoft Entra ID)

4\. Azure SQL Database



\## Three (3) Advantages

1\. Best Microsoft ecosystem integration

2\. Strong hybrid cloud support (Azure Arc, Azure Stack)

3\. Enterprise/government compliance trust



\## Typical Enterprise Use Cases

\- Migrating Windows Server/AD environments

\- Hybrid cloud deployments

\- .NET application hosting

\- Enterprise identity management
