# Laboratory 05 – Cloud Data Engineer

## Mission Overview
In this lab, I set up an object storage server called MinIO using Docker. I created a storage bucket named `client-photos` and uploaded a test file to show that the storage works.

## Objectives
- Learn the difference between Block, File, and Object Storage.
- Set up MinIO (an S3-like storage server) using Docker.
- Open the MinIO web console using port forwarding.
- Create a bucket and upload a file.
- Write documentation using Markdown.

## Tools Used
- Docker
- MinIO
- KillerCoda Ubuntu Playground
- Git and GitHub

## Skills Learned
- How to run a container with environment variables.
- How object storage buckets work.
- The difference between block, file, and object storage.
- How to write clear documentation in Markdown.
- More confidence using the Linux terminal.
